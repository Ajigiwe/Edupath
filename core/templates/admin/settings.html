SMS Setup Guide:

  1. Termii (recommended for Ghana): Sign up at termii.com, get API key from dashboard. Sender ID max 11 chars.
  2. Twilio: Get Account SID and Auth Token from Twilio Console. Use format "account_sid:auth_token" as API key.
  3. Custom HTTP: Provide an endpoint that accepts POST with JSON {phone, message, sender_id}. Auth via Bearer token (API Key field).

How to get your Paystack keys:

  1. Log in to your Paystack Dashboard
  2. Go to Settings → API Keys & Webhooks
  3. Copy your Live Public Key and Live Secret Key
  4. Paste them above and save
